# docs — tài liệu

- Tiếng Việt có dấu, ngắn, có ví dụ lệnh chạy được; nêu rõ **giới hạn đã biết**, đừng hứa quá.
- Đổi hành vi (bảo mật, triển khai, phát hành, quyền) thì sửa tài liệu tương ứng **trong cùng thay đổi**: `SECURITY.md` (mô hình bảo mật), `DEPLOY.md`, `RELEASE.md`, `CICD.md`, `DIAGNOSTICS.md`.
- Không ghi bí mật, mật khẩu, email/dữ liệu thật; dùng giá trị mẫu (`khach01`, `a@neu.edu.vn`).
- `docs/training/` và `docs/course/` là học liệu cho giảng viên/sinh viên: giọng sư phạm, đừng trộn nội dung kỹ thuật vận hành vào đó.
- Nhật ký thay đổi nằm ở `CHANGELOG.md` gốc (không phải trong `docs/`).
